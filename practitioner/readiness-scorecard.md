# RAISE-HRI Deployment Readiness Scorecard

[← Deployment checklist](deployment-checklist.md)

This is a **qualitative review aid**, not a certified safety score.

Rate each area:

- **0 — not addressed**
- **1 — partially defined**
- **2 — tested in controlled conditions**
- **3 — tested under representative field conditions**

| Area | 0 | 1 | 2 | 3 | Evidence / notes |

| Safety + usability evaluation | ☐ | ☐ | ☐ | ☐ | |
| Field-condition validation | ☐ | ☐ | ☐ | ☐ | |

## Interpretation

Do not collapse the table into one “readiness number” without examining the weak dimensions. A single unresolved failure-recovery or authority problem can dominate the deployment risk even when other dimensions are mature.
