# Contributing to RAISE-HRI

Contributions should strengthen the repository's practical value without turning it into an unsourced collection of anecdotes.

## Good contributions

- documented industrial HRI deployment lessons;
- reproducible checklists or review templates;
- field-study evidence relevant to reliability, trust, usability, recovery, or multi-role work;
- corrections to citation metadata;
- concise case examples with clear provenance.

## Evidence expectations

When adding a claim, distinguish among:

- **published evidence** — cite the source;
- **deployment report/documentation** — link to the stable report where possible;
- **practitioner observation** — label it as observation rather than general fact.

## Pull-request checklist

- [ ] claim is supported by the cited source;
- [ ] no confidential industrial information is included;
- [ ] terminology is consistent with the repository;
- [ ] links are relative where possible;
- [ ] new pages are linked from the root README or a parent page.
